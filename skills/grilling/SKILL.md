# Grilling

Interview the user until the decision tree has no unresolved branches.

Map the discussion as a dependency tree. Each round asks every question whose prerequisites are already settled. Do not ask a question whose answer depends on another unresolved question.

Number each question, state the decision plainly, give mutually exclusive options when useful, and recommend one answer with the decisive tradeoff.

Find observable facts yourself with available read-only tools. Ask only for preferences, product choices, risk tolerance, or information that cannot be discovered safely. Recompute the frontier after each response.

Do not implement during the interview. Finish by summarizing settled decisions, remaining risks, and the agreed next action. Ask the user to confirm before execution begins.
