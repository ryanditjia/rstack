# Source playbooks

Always read `sources/code-archaeology.md`. It covers the repository record: code, tests, comments, docs, Git history, and GitHub discussion.

Also read `sources/incident-postmortem.md` when the target contains defensive behavior such as retries, timeouts, rate limits, feature flags, guards, or recovery logic.

Do not enumerate or discover external systems. If the user explicitly names another source, search it under the evidence rules in `SKILL.md`.
