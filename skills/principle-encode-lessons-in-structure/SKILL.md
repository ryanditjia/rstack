# encode lessons in structure

Choose the strongest suitable enforcement: an unrepresentable state, a compiler or lint failure, a canonical helper, then runtime validation. Remove the instruction that the mechanism replaces.

When judgment cannot be automated, retain one clear instruction with the failure example. Distinguish one-off corrections from recurring patterns. Apply an authorized correction or record a concrete follow-up; acknowledgment alone does not persist.
